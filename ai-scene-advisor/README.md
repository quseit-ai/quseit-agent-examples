# AI 场景顾问

聊几分钟访客的工作或学习，帮他找到 AI 最值得先用起来的一两个场景，结束时给出一张可落地的「AI 场景建议卡」；同时把访客**明确说出**的信息（身份、AI 使用水平、痛点、团队人数、是否愿意约顾问、具体需求、联系方式）整理进「记录表」，创作者在智能体详情的「记录」里按字段自动汇总查看。

- 线上示例：https://agent.quseit.com/s/ai-advisor
- 引擎：对话（无沙箱）；收费：免费；联网搜索：关闭
- 一句话看点：**用聊天代替问卷**——访客边聊边得到建议，创作者拿到结构化的线索数据。

## 目录

```
ai-scene-advisor/
├── README.md              # 本文件
├── skill/SKILL.md         # 技能：对话规则（上传到「技能库」的就是它）
├── agent.json             # 页面与运行配置（标题、地址、开场白、引导问题、提示语、引擎、模型、温度……）
├── record_schema.json     # 记录表定义（7 个字段）
└── scripts/publish_in_container.py   # 平台运营用的一键发布脚本（普通创作者不需要）
```

`agent.json` 与 `record_schema.json` 就是线上版本的配置，下文后台操作里要填的内容都以它们为准。

## 适用场景

- 做 AI 培训、咨询、工具服务的团队，需要在官网或活动页放一个「先聊聊、再约顾问」的入口。
- 想把访客的需求从聊天里结构化沉淀下来（而不是让访客填一张问卷），并从中区分出愿意约顾问的高意向线索。
- 也可作为「访谈 + 记录表」类智能体的模板：换掉技能文案和字段，就能做测评、报名、需求调研。

## 对话设计要点

对话规则全部写在 [`skill/SKILL.md`](skill/SKILL.md) 里，核心有这几条：

1. **破冰**：简短打招呼，给 2–3 个低门槛入口让访客挑，不一上来就问身份。
2. **每轮只问一个主要问题**：先回应，再给一点信息，最后抛一个具体、好回答的问题；身份、团队人数等背景在聊场景时自然带出，不单独盘问。
3. **尽早给价值**：第 2–3 轮就针对访客已说的场景给一个小建议，让他在聊的过程中就有收获，而不是都留到最后。
4. **不推断**：只记访客明确表达的信息，并附原话作依据；「我们有十几个销售」只说明销售人数，不等于团队规模；「写代码」不等于能搭建 AI 应用。访客更正时以新说法为准；不想回答的问题直接跳过，不追问。
5. **联系方式后置**：只在访客表示愿意约顾问之后才问，并说明只用于顾问联系；不愿意留就告诉他随时可以再回来。
6. **建议卡 + 完成**：信息差不多或访客想结束时，输出不超过 200 字的「AI 场景建议卡」（场景概括 / 1–3 条明天就能试的做法 / 下一步），并在保存记录时设置 `complete=true`、附一句话总结——这条记录就算「已完成」。

## 页面与运行配置

[`agent.json`](agent.json) 里各项的含义与取值：

| 配置项 | 值 | 说明 |
| --- | --- | --- |
| `title` | AI 场景顾问 | 智能体名称 |
| `slug` | `ai-advisor` | 访问地址后缀，对外地址为 `/s/ai-advisor`；全平台唯一，被占用就换一个 |
| `description` | 见文件 | 一句话描述（链接预览、列表里用） |
| `greeting` | 见文件 | 开场白：访客进来看到的第一句话，也是首屏标题 |
| `starter_questions` | 3 条 | 引导问题：访客进来先看到的三个可点问题，`label` 是按钮上的字，`prompt` 是点击后发出的话 |
| `input_placeholder` | 见文件 | 输入框提示语：对话页底部输入框里的灰色提示字（不是开场白） |
| `engine` | `chat` | 运行引擎「对话（无沙箱）」；**记录表只对这个引擎生效** |
| `model` / `default_provider` | `deepseek-flash` / `deepseek` | 模型与供应商（密钥在平台后台配置，这里不含任何密钥） |
| `temperature` | 0.7 | 温度 |
| `pricing_mode` / `free_rounds` | `free` / 0 | 免费，访客不付点数 |
| `web_search_enabled` | false | 不开联网搜索 |
| `is_service_page_enabled` / `is_api_enabled` | 1 / 0 | 开启对外页面 / 不开 API 接入 |

## 记录表字段说明

记录表让智能体在对话中，把访客明确提供的信息按字段整理成**一条记录**（一次会话一条，随对话更新；保存时标记 `complete=true` 才算「已完成」）。创作者在「记录」tab 里按字段类型看到自动汇总：选择类出分布，数值出均值 / 中位数，文本出明细与热词。定义见 [`record_schema.json`](record_schema.json)（`version: 1`，`scope: session`）。

| 字段 key | 显示名 | 类型 | 含义 | 备注 |
| --- | --- | --- | --- | --- |
| `identity` | 身份 | 单选 | 学生 / 职场人士 / 创业者或管理者 / 其他 | 访客自己说明才记；明细表单独成列 |
| `ai_level` | AI 使用水平 | 单选 | L0 没用过 / L1 偶尔用 / L2 经常用 / L3 能搭建或开发 | 按访客描述判断，不从职业推断；明细表单独成列 |
| `pain_points` | 痛点 | 多选 | 写作文案 / 会议纪要 / 资料检索整理 / 数据报表 / 客户沟通跟进 / 编程开发 / 其他 | 不在列表里的选「其他」，原话写进「具体需求」 |
| `team_size` | 团队人数 | 数值 | 范围 0–100000 | 只记访客明确说出的团队总人数；单个岗位人数不算，约数取整 |
| `want_consult` | 是否愿意约顾问 | 是 / 否 | 明确愿意记「是」，明确不需要记「否」 | 没表态不记；决定能不能向访客要联系方式 |
| `need_detail` | 具体需求 | 长文本 | 一两句话概括最想用 AI 解决的场景 | **必填**：AI 会主动问到；保留访客原话里的关键细节 |
| `contact` | 联系方式 | 短文本 | 愿意约顾问后主动留下的手机号 / 微信 / 邮箱 | **敏感信息**：后台表格默认打码，导出时提醒；访客不愿留就不记 |

几个概念：

- **标识（key）**：字段的稳定身份。统计按它合并历史数据，所以上线后不要随便改；改了等于新建字段，旧数据会归入「已停用字段」。只能用小写字母、数字和下划线，以字母开头。
- **判断说明**：写给 AI 看的“什么情况记什么值”，直接决定记得准不准，需要时可以按自己的业务调整。
- **必填**：只是让 AI 主动问到，不会拦截写入。
- **敏感信息**：后台列表默认显示 `••••••`，点击才显示；导出 CSV 时会弹窗提醒包含个人信息。
- **显示在列表**：在「记录」明细表里单独成列；所有字段都不勾时，默认取前 3 个字段。
- 已经有记录数据的字段**不能改类型**（要改请新建一个字段）。

## 在 QUSEIT 后台从零创建

以下是普通创作者的做法，全部在 QUSEIT 创作者后台完成，不需要任何命令行权限。

### 0. 准备

1. 用创作者账号登录后台。
2. 左侧栏「账号设置」→「模型与密钥」：配置 **DeepSeek** 的模型密钥（本示例用 `deepseek-flash`，没配密钥会导致后面发布、更新版本失败）。如果你所在的环境由平台统一提供模型，这一步可跳过，以后台提示为准。
3. 左侧栏「我的钱包」：确认点数余额大于 0（余额用尽时你名下的智能体会暂停接待）。

### 1. 把技能打成 zip 包

后台上传的是 zip 包，且包内必须是「`<技能名>/SKILL.md`」结构。在本仓库根目录执行：

```bash
cd ai-scene-advisor
mkdir -p build/ai-scene-advisor
cp -R skill/. build/ai-scene-advisor/
(cd build && zip -r ai-scene-advisor.zip ai-scene-advisor)
```

得到 `ai-scene-advisor/build/ai-scene-advisor.zip`（`build/` 已被 `.gitignore` 忽略）。

### 2. 上传技能到技能库

1. 左侧栏进入「技能库」，点右上角「发布技能」，进入「发布技能」页面。
2. 在「上传技能包」卡片点「选择文件」，选中 `ai-scene-advisor.zip`。
3. 上传成功会提示「「ai-scene-advisor」已加入技能库」，返回「技能库」就能看到这张技能卡。

### 3. 用技能发布成智能体（三步向导）

1. 在「技能库」里点技能卡「选择」勾选 `ai-scene-advisor`，点页面底部的「发布成智能体 →」，打开「发布成智能体」向导。
2. **第 1 步「身份」**，按 [`agent.json`](agent.json) 填写：
   - 名称：`AI 场景顾问`
   - 角色设定：线上版本**留空**，全部对话规则都在技能 `SKILL.md` 里。向导会自动按技能起草一版，请清空它（或保留也可，但会和技能规则叠加）。
   - 开场白：填 `agent.json` 的 `greeting`
   - 输入框提示语：填 `input_placeholder`
   - 引导问题：在输入框里依次填 `starter_questions` 里 3 条的 `prompt`（完整一句话），每条回车确认。后台界面里一条引导问题只有一句话，按钮上的字和点击后发出的话相同；线上版本按钮上用的是更短的 `label`，这个差异只影响按钮文字，不影响对话。
   - 运行引擎：选「**对话（无沙箱）**」
   - 点「下一步：收费 →」
3. **第 2 步「收费」**：选「免费」，点「下一步：上线 →」。
4. **第 3 步「上线」**：「访问地址」填 `ai-advisor`（提示「已被占用」就换一个），主题色随意，不勾「需要密码才能访问」，核对「上线确认」里的名称 / 引擎后点「确认上线 →」。

上线成功后会跳到「智能体」列表，里面出现「AI 场景顾问」。

### 4. 在「编辑」里补全模型和记录表

1. 「智能体」列表里点开「AI 场景顾问」进入详情页，点右上角「编辑」，打开「编辑智能体」弹窗。
2. 「模型与引擎」一段：模型选 `deepseek-flash`（DeepSeek 分组下）；温度拖到 `0.7`；运行引擎确认是「对话（无沙箱）」；「允许联网搜索」保持关闭。
3. 「身份与开场」一段：核对开场白、输入框提示语、引导问题是否与 `agent.json` 一致，有出入可以在这里改（这三项保存即生效）。
4. 拉到「记录表」一段，打开「开启记录表」开关，然后点 7 次「添加字段」，按下面逐个配置（点字段左侧的「展开」才能看到全部配置项）：

#### 字段 1：身份

| 配置项 | 填写 / 选择 |
| --- | --- |
| 显示名 | `身份` |
| 类型 | 单选 |
| 标识（key） | `identity`（展开字段后在「标识（key）」里把自动生成的值改成它） |
| 选项（逐个点「添加选项」，把自动生成的「选项标识」改成下列标识，并填「选项文案」） | `student` → 学生；`professional` → 职场人士；`founder_manager` → 创业者或管理者；`other` → 其他 |
| 判断说明 | 访客自己说明的身份。在读学生选「学生」；受雇在职选「职场人士」；自己创业、当老板或带团队的负责人选「创业者或管理者」；都不是选「其他」。访客没说就不记，不要按话题猜。 |

### 5. 更新版本（必须）

回到详情页，点右上角「**更新版本**」。**记录表、运行引擎、模型、温度、联网搜索、角色设定这类改动都只有点了「更新版本」之后才对新会话生效**；只点「保存」不会重新打包。开场白、引导问题、输入框提示语、主题色保存即生效。

> 注意：已经在进行中的对话不受影响，改完后请开一个新对话来验证。

### 6. 验证并查看数据

1. 打开 https://agent.quseit.com/s/ai-advisor（或你自己的 `/s/<slug>`），登录访客账号后用「我最近有件事特别费时间」之类的话开始对话，走完整个流程，聊到愿意约顾问并留下联系方式，等待建议卡输出。
2. 回到后台，智能体详情页顶部 tab 里点「**记录**」（配置并更新版本后才会出现；直接访问时会出现「去配置记录表」引导）。
3. 「记录」tab 从上到下是：
   - **筛选条**：时间范围（7 / 30 / 90 日）、版本、「仅已完成 / 含进行中」、「按访客去重」、「显示敏感信息」、「导出 CSV」。
   - **漏斗**：开始对话 → 产生记录 → 已完成，以及完成率（已完成 ÷ 产生记录）。
   - **字段统计**：每个字段一张卡。选择类显示各选项的人数与比例，点选项可作为筛选条件，下方统计与明细一起变化；数值类显示均值 / 中位数 / 分布；文本类显示热词与原话。回答不足 30 人会标「样本较少」。
   - **明细表**：时间、访客、状态（已完成 / 进行中）、一句话总结，以及勾了「显示在列表」的字段（本示例是「身份」和「AI 使用水平」）。「联系方式」默认打码，点「显示」或打开页头的「显示敏感信息」才显示原文。
   - **记录详情**：点明细表任意一行，弹窗里能看到该访客的每个字段、AI 记录时附的原话依据，以及完整对话原文。

### 常见问题

- **「更新版本」失败，提示没有配置模型密钥**：到「账号设置 → 模型与密钥」配置 DeepSeek 密钥，或在「编辑」里换成已配置密钥的供应商的模型，再更新版本。
- **记录 tab 没有数据**：确认运行引擎是「对话（无沙箱）」、已点过「更新版本」，并且是在更新之后新开的对话；进行中的记录默认被「仅已完成」筛掉，可切到「含进行中」。
- **想改字段**：回「编辑」改记录表并「保存」，再点「更新版本」。已有数据的字段不能改类型。

## 用脚本发布（平台运营使用）

[`scripts/publish_in_container.py`](scripts/publish_in_container.py) 是给**平台运营**用的：在能 import 平台后端 `app` 包的环境里，用平台内部函数把上面的后台步骤一次完成（上传技能 → 由技能发布 → 补开场白 / 引导问题 / 提示语 / 记录表 → 更新版本）。**普通创作者走上面的后台 UI 即可，不需要也无法使用这个脚本。**

```bash
python publish_in_container.py --email <创作者邮箱> --slug ai-advisor
```

用法、前提与调用的平台函数见脚本顶部的说明。
